Insurance Agent Management PortalA modern, responsive web-based platform designed for insurance agencies and administrators to manage agent onboarding, commission tracking, client portfolios, policy lifecycle management, performance analytics, and administrative tasks in real time.📋 Table of ContentsProject OverviewKey FeaturesSystem ModulesDesign Guidelines & UI/UXTech StackGetting Started & Setup InstructionsProject StructureFuture Enhancements🎯 Project OverviewThe Insurance Agent Management Portal simplifies agent management and administrative operations for insurance companies. Built as a single-page React application powered by Tailwind CSS and Lucide icons, it provides an intuitive dashboard for managing the complete lifecycle of insurance agents, client relationships, policies, and earnings.Core Objectives:Centralized Dashboard: Instant high-level metrics on active agents, total premiums, active policies, and dynamic visual analytics.Agent Lifecycle Management: Streamlined onboarding, status management (Active, Onboarding, Inactive), performance tracking, and direct agent communication.Client & Policy Oversight: Comprehensive views for clients and policies with quick search, filter, and detail modal capabilities.Financial Tracking: Real-time commission calculators, payout tracking, and downloadable financial reports.Security & Access Control: Role-based access with simulated authentication flows (Login screen, password visibility toggles, session persistence).✨ Key FeaturesAuthentication & Security:Secure Login interface with support for Admin, Agent, and Manager roles.Quick demo login credentials for instant platform testing.Interactive Analytics:Visual charts showing monthly sales performance, policy distribution across categories (Auto, Life, Health, Property, Commercial), and top-performing agents.Agent Directory:Real-time search by name, email, or license number.Filter agents by status (Active, Onboarding, Inactive).Modal view for viewing comprehensive agent profiles, assigned clients, and performance metrics.Commission Calculator & Reports:Dynamic commission calculation tool based on premium amount, policy type, and agent rank (Junior, Senior, Executive).Export functionality for monthly financial and performance summaries.System Settings & Personalization:Customizable system notifications, dark/light theme preferences, currency settings, and security controls.🧩 System ModulesModuleDescriptionKey FunctionsAuthenticationRole-based gateway into the portalLogin, Password Reset, Quick Demo Access, Role SelectionDashboard clarity, accessibility, and intuitive interaction:Color Palette:Primary: Slate / Indigo (#1e293b, #4f46e5) — builds trust and professional authority.Secondary / Accent: Emerald Green (#10b981) for positive indicators/commissions, Amber (#f59e0b) for pending/warnings, and Crimson (#ef4444) for inactive/errors.Background: Soft Gray (#f8fafc) in light mode; Slate (#0f172a) in dark mode.Typography:
